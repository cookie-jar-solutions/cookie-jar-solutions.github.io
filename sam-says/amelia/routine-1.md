# Amelia’s Workout Split

## Abbreviations

- **AMRAP** — As many reps as possible
- **SUP** — Supinated
- **PRO** — Pronated
- **SL** — Single Leg
- **SA** — Single Arm
- **DB** — Dumbbell

---

## Monday — Chest / Triceps / Core

**3 sets of 12–15 reps**

- Cable chest flys (high angle to low)
- SA cable chest extensions
- Pushups (last set AMRAP)
- Overhead cable extensions
- Standing rope cable extensions
- SA DB tricep kickbacks (each arm)
- DB Russian twists
- Lying leg lifts
- SA side planks

## Tuesday — Back / Biceps / Cardio

**3 sets of 10–12 reps**

- PRO rear delt flys
- SA seated cable row (each arm)
- Cable rope lat pulldown
- SUP bar lat pulldown (for biceps; last set AMRAP)
- Seated DB hammer curls
- **20 minutes StairMaster:** Alternate between levels 5 and 8 every 2 minutes.

## Wednesday — Shoulders / Legs

**Sets 1–2:** 12 reps each  
**Set 3:** 8–10 reps, slow tempo

- SA lateral raises (each arm)
- Standing PRO DB front raises (each arm)
- Bus drivers (10 lb plate)
- SL cable standard kickbacks (each leg)
- SL cable crossover kickbacks (each leg)
- DB goblet squat (add a wedge if available)
- DB walking lunges (focus on spacing of your legs)
- Vertical leg press (wide foot placement)

## Thursday — Rest and Recovery

## Friday — Back / Biceps / Cardio

**3 sets of 10–12 reps**

- PRO rear delt flys
- SA seated cable row (each arm)
- Cable rope lat pulldown
- SUP bar lat pulldown (for biceps; last set AMRAP)
- Seated DB hammer curls
- **20 minutes StairMaster:** Alternate between levels 5 and 8 every 2 minutes.

## Saturday — Legs / Core

**Sets 1–2:** 12–15 reps each  
**Last set:** 10–12 reps

- Hack squat (go for maximum range of motion)
- Neutral lying hamstring curl (focus on bringing ankles to glutes)
- Seated leg extensions (last set AMRAP)
- SL cable standard kickbacks (each leg)
- SL cable crossover kickbacks (each leg)
- Hip adductors (last set AMRAP)
- Hip abductors (last set AMRAP)
- Timed planks (keep a log of times to beat)
- Flutter kicks (3 timed sets; set a 30-second timer)

## Sunday — Well-Earned Rest Day!
