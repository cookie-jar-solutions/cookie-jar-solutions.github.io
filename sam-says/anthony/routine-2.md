# Anthony’s Workout Split

## Abbreviations

- **AMRAP** — As many reps as possible
- **SUP** — Supinated
- **PRO** — Pronated
- **SL** — Single Leg
- **SA** — Single Arm
- **DB** — Dumbbell

---

## Monday

### Chest / Back / Core

*3 sets of 12–15 reps*

- Pec Deck chest flys
- DB flat chest press (aim for full range of motion)
- Riser deficit push-ups (last set AMRAP)
- Chest-supported T-bar row
- Neutral grip lat pulldown
- Seated close-grip cable row (remember — pull to your hips)
- DB VIPR Style Twists
- Lying leg lifts
- Bosu platform planks (60-second timer)

## Tuesday

### Shoulders / Arms / Cardio

*3 sets of 10–12 reps*

- PRO rear delt flys (add a 4th set AMRAP)
- Seated DB shoulder press (stop DB at ear level — don’t overwork)
- Cable rope upright row
- PRO DB front raise
- Seated DB hammer curls
- Preacher curl (3rd set AMRAP)
- Overhead cable rope extensions
- SUP cable short bar extensions
- 20 mins incline treadmill (Level 8 incline / Speed 3.0)

## Wednesday

### Legs (Make sure you carb up!)

- *1st and 2nd sets: 12 reps*
- *3rd set: 8–10 reps, max range*

- SL Bulgarian Splits (do a warm-up set for rep range please)
- Wide stance vertical leg press
- Neutral lying hamstring curl (remember to point your toes out / Plantar Flexion)
- Seated unilateral leg extension (each leg)
- Hack Squat (add a wedge if you need for better ankle flexion)
- Hip Adductors (great for opening up hip mobility / building Psoas)

## Thursday

### Rest and Recovery

## Friday

### Chest / Back / Core

*3 sets of 12–15 reps*

- Neutral bench DB flys
- Incline bench DB press
- Riser deficit push-ups (last set AMRAP)
- Chest-supported T-bar row
- Wide-grip lat pulldown
- SA bent-over DB row (drive your elbow past the hip)
- DB can openers (remember — keep your range open)
- Kettlebell kneeling crunches
- Cable Pallof press (slow and proper form is paramount)

## Saturday

### In Session Day (Shoulders / Arms / Cardio)

## Sunday

### Rest and Recovery
